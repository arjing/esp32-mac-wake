# ESP32 Mac 远程唤醒

通过 MQTT 接收指令，使用 ESP32-S3 模拟蓝牙鼠标，尝试唤醒已配对的睡眠 Mac。无需依赖 Mac 的网络唤醒功能。效果取决于机型、macOS 版本、蓝牙连接与睡眠状态；不能从关机状态开机。

## 硬件和编译

- ESP32-S3-DevKitC-1（8 MB Flash）及 USB 供电。
- 使用 PlatformIO 打开本项目，执行 `pio run` 编译、`pio run -t upload` 烧录。
- 蓝牙鼠标库从上游获取，其授权条款请向上游确认；参见 [ESP32-BLE-Mouse](https://github.com/T-vK/ESP32-BLE-Mouse)。

## 配置

1. 首次启动连接 `ESP32-Setup-XXXX` 热点，访问 `http://192.168.8.1`。
2. 填写 2.4 GHz Wi-Fi、蓝牙名称和 MQTT 设置。使用 TLS 证书验证时需粘贴 PEM CA 证书。
3. 保存后重启，在 Mac 蓝牙设置中配对设备。
4. 向 MQTT 主题 `wol` 发送字符串 `1` 触发唤醒；状态及心跳发布到 `esp32-heart`。
5. 正常运行时长按 BOOT 约 3 秒可重新开启配置热点；Wi-Fi 断线后持续重试。

## 安全与限制

配置热点目前无密码且配置页没有身份验证，仅在可信环境配置。配置数据保存在设备闪存；不要将个人凭据提交到仓库。MQTT 主题目前为固定值，多台设备共用主题时可能同时响应；应在可信网络使用，并为 MQTT 设置认证及访问控制。普通连接没有加密，不验证证书的 TLS 无法验证服务器身份。发布、商用前请自行测试可靠性与依赖授权。
